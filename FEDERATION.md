# Federation Member Contract

**Member:** `private-to-public-release-gate`  
**Role:** Private-to-public publication boundary  
**Canonical parent:** [Growth Architecture OS](https://github.com/silvermanjared-web/growth-architecture-os)

## Provides

- privacy findings
- explicit export decisions
- Git-aware drift evidence
- release pass/fail evidence

## Can consume

- private canonical source
- reviewed public distribution
- publication policy

Consumption is optional. This repository remains independently usable and does not require another federation member merely to function.

## Authority

Owns release-boundary validation only; it does not authorize or control member runtime execution.

Horizontal interoperability does not transfer authority between members.

## Federation principle

This repository participates in the public portfolio federation through stable concepts, artifacts, and capability contracts. Runtime coupling is added only when it creates material operating value.

See the canonical [Public Portfolio Federation](https://github.com/silvermanjared-web/growth-architecture-os/blob/main/docs/public-federation.md).
